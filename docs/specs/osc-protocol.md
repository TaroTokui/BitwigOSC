# OSC のアドレスの決まり

TouchOSC と BitwigOSC 拡張のあいだでやりとりするメッセージ。
`touchosc/BitwigOSC.tosc` は、この決まり(`OscCommand`)を使ってコードから作る。

## 形

```
/{番号}/{操作}  値
```

- 番号は TouchOSC のレイアウトの **tag**(アドレスは `/` + tag + `/volume` のように組み立てる)
- トラックは **1 から**数える。`/1/...` がミキサーに今出ている 8 本のいちばん上の行、`/8/...` までの 8 本(Bitwig と同じく上から下に並ぶ。`/mixer/scrollUp`・`scrollDown` で 1 本ずつずらせる)。FX トラックは数えない。グループは 1 本と数え、中のトラックは数えない
- **0 はトランスポート**(曲全体の操作)
- 決まりの外のアドレスや、数として読めない引数は、コンソールに出すだけで何もしない

## TouchOSC → 拡張

| アドレス | 引数 | 意味 |
|---|---|---|
| `/ping` | なし(ボタンなら float) | 疎通の確認。`/pong` を返す |
| `/{1-8}/volume` | float 0.0〜1.0 | 音量(Bitwig のフェーダーの位置。範囲の外は端に寄せる) |
| `/{1-8}/pan` | float 0.0〜1.0 | パン(0.5 が中央) |
| `/{1-8}/mute` | float 1.0 / 0.0 | ミュートのオン / オフ |
| `/{1-8}/solo` | float 1.0 / 0.0 | ソロのオン / オフ |
| `/{1-8}/arm` | float 1.0 / 0.0 | 録音待機のオン / オフ |
| `/{1-8}/active` | float 1.0 / 0.0 | トラックの有効 / 無効 |
| `/0/playState` | float 1.0 / 0.0 | 再生 / 停止 |
| `/0/loopEnabled` | float 1.0 / 0.0 | アレンジャーのループのオン / オフ |
| `/0/stop` | float 1.0 / 0.0 | 再生を止める。押したとき(0.5 以上)だけ動く。状態ではないので送り返さない(止まったことは `/0/playState` の 0.0 で届く) |
| `/mixer/scrollUp`・`scrollDown` | float 1.0 / 0.0 | ミキサーの 8 本を 1 本ぶん上 / 下へ。押したとき(0.5 以上)だけ動く。左右はない(ミキサーにシーンはない)。ページ 2 と同じ範囲なので、`/clip/scrollUp`・`scrollDown` と同じ動き |
| `/sync` | なし | 今の状態を全部送り返してもらう。`BitwigOSC.tosc` は、開いたときにスクリプト(`init()`)で 1 回送る |

- オン・オフの値は、0.5 以上をオンとする。int と bool も受ける。
- ボタンは押すたびに新しい状態を送るトグルとして扱う。拡張は「切り替える」のではなく、「送られた状態にする」。

## 拡張 → TouchOSC

拡張は Bitwig の今の状態を、受け取るときと同じアドレスで送り返し、レイアウトの表示を揃える(レイアウトのコントロールは受信も有効にしてある)。値は `/0/position` の文字のほかは float。

送るのは次のときです。
- Bitwig 側で値が変わったとき
- 拡張が起動した直後
- `/sync` を受けたとき

| アドレス | 引数 | 意味 |
|---|---|---|
| `/pong` | なし | `/ping` への返事 |
| `/{1-8}/volume`・`pan` | float 0.0〜1.0 | 上の表と同じ |
| `/{1-8}/mute`・`solo`・`arm`・`active` | float 1.0 / 0.0 | 上の表と同じ |
| `/0/playState`・`loopEnabled` | float 1.0 / 0.0 | 上の表と同じ |
| `/0/position` | string | 今の小節.拍(例 `12.3`)。拍子の分母を 1 拍とする。拍が変わったときだけ送る(4/4・120 BPM で 1 秒に 2 通)。送り返す専用で、受け取らない |
| `/{1-8}/colorR`・`colorG`・`colorB` | float 0.0〜1.0 | トラックの色。レイアウトの箱(box)の色になる。送り返す専用で、受け取らない。トラックがない位置には黒(0, 0, 0)を送る。背景と同じ黒なので、箱は見えなくなる |

## ヘッダー

`BitwigOSC.tosc` の画面の上(タブの帯の上)には、どのページを開いていても出る部品を置く。左から再生(`/0/playState`)、停止(`/0/stop`)、ループ(`/0/loopEnabled`)、小節.拍の表示(`/0/position`)。どれもトランスポートなので、番号は 0。

- 再生のボタンは受信もするトグルで、Bitwig 側で再生・停止しても状態が揃う。灰色の箱の上に、オンのときだけ Bitwig の橙で塗られるボタンと白い ▶ を重ねる(止まっていると灰色)。
- 停止のボタンはモーメンタリで、受信しない。再生と同じ灰色の上に白い ■。

## ページ 2(クリップ)

レイアウトの 2 枚目のタブ「Clips」は、Bitwig のクリップランチャーを 8 トラック × 8 シーンの範囲で操作する。
トラックの範囲はミキサー(ページ 1)と同じ 8 本。どちらのページで上下にずらしても、両方のページのトラックと Bitwig の枠が一緒に動く。シーンの範囲(左右)はページ 2 だけのもの。ページ 2 は Bitwig のアレンジ画面のランチャーと同じく、行がトラック、列がシーン。
番号は**範囲の中の位置**(1〜8)で、曲の何番目のトラック・シーンかではない。今の範囲は、Bitwig のクリップランチャーに枠で出る。

### TouchOSC → 拡張

どれも値が 0.5 以上(押したとき)だけ動く。ボタンはモーメンタリで、離したときの 0.0 は無視する。

| アドレス | 引数 | 意味 |
|---|---|---|
| `/clip/{1-8}/{1-8}/launch` | float 1.0 / 0.0 | トラック・シーンのマスのクリップを起動する(空のマスなら、そのトラックを止める。Bitwig の動き) |
| `/clip/{1-8}/stop` | float 1.0 / 0.0 | トラックのクリップを止める |
| `/scene/{1-8}/launch` | float 1.0 / 0.0 | シーンを丸ごと起動する |
| `/clip/scrollUp`・`scrollDown` | float 1.0 / 0.0 | トラックの範囲を 1 本ぶん上 / 下へ(ページ 1 も一緒に動く) |
| `/clip/scrollLeft`・`scrollRight` | float 1.0 / 0.0 | シーンの範囲を 1 列ぶん左 / 右へ |

### 拡張 → TouchOSC

ボタンは受信しない(モーメンタリのボタンに 1.0 を送ると、次に押しても値が変わらず送られなくなるため)。状態は、ボタンの下の色の箱で見せる。

| アドレス | 引数 | 意味 |
|---|---|---|
| `/clip/{1-8}/{1-8}/colorR`・`colorG`・`colorB` | float 0.0〜1.0 | マスの色。録音中は赤、録音の待機中は暗い赤、クリップなしは黒、再生中はクリップの色、再生の待機中は 70%、止まっているときは 35% の明るさ |
| `/clip/{1-8}/colorR`・`colorG`・`colorB` | float 0.0〜1.0 | 範囲の中のトラックの色。トラックがない位置は黒 |

`/sync` を受けたときは、ミキサーとトランスポートの 74 通と小節の表示の 1 通に加えて、ページ 2 の 216 通(マス 64 × 3 + トラック 8 × 3)を送る。
