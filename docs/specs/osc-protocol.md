# OSC のアドレスの決まり

TouchOSC と BitwigOSC 拡張のあいだでやりとりするメッセージ。
`touchosc/BitwigOSC.tosc` は、この決まり(`OscCommand`)を使ってコードから作る。

## 形

```
/{番号}/{操作}  値
```

- 番号は TouchOSC のレイアウトの **tag**(アドレスは `/` + tag + `/volume` のように組み立てる)
- トラックは **1 から**数える。`/1/...` がミキサーの左端のトラック、`/8/...` までの 8 本。FX トラックは数えない。グループは 1 本と数え、中のトラックは数えない
- **0 はトランスポート**(曲全体の操作)
- 決まりの外のアドレスや、数として読めない引数は、コンソールに出すだけで何もしない

## TouchOSC → 拡張

| アドレス | 引数 | 意味 |
|---|---|---|
| `/ping` | なし(ボタンなら float) | 疎通の確認。`/pong` を返す |
| `/{1-8}/volume` | float 0.0〜1.0 | 音量(Bitwig のフェーダーの位置。範囲の外は端に寄せる) |
| `/{1-8}/pan` | float 0.0〜1.0 | パン(0.5 が中央) |
| `/{1-8}/mute` | float 1.0 / 0.0 | ミュートのオン / オフ |
| `/{1-8}/solo` | float 1.0 / 0.0 | ソロのオン / オフ |
| `/{1-8}/arm` | float 1.0 / 0.0 | 録音待機のオン / オフ |
| `/{1-8}/active` | float 1.0 / 0.0 | トラックの有効 / 無効 |
| `/0/playState` | float 1.0 / 0.0 | 再生 / 停止 |
| `/0/loopEnabled` | float 1.0 / 0.0 | アレンジャーのループのオン / オフ |
| `/sync` | なし | 今の状態を全部送り返してもらう。`BitwigOSC.tosc` は、開いたときにスクリプト(`init()`)で 1 回送る |

- オン・オフの値は、0.5 以上をオンとする。int と bool も受ける。
- ボタンは押すたびに新しい状態を送るトグルとして扱う。拡張は「切り替える」のではなく、「送られた状態にする」。

## 拡張 → TouchOSC

拡張は Bitwig の今の状態を、受け取るときと同じアドレスで送り返し、レイアウトの表示を揃える(レイアウトのコントロールは受信も有効にしてある)。値はすべて float。

送るのは次のときです。
- Bitwig 側で値が変わったとき
- 拡張が起動した直後
- `/sync` を受けたとき

| アドレス | 引数 | 意味 |
|---|---|---|
| `/pong` | なし | `/ping` への返事 |
| `/{1-8}/volume`・`pan` | float 0.0〜1.0 | 上の表と同じ |
| `/{1-8}/mute`・`solo`・`arm`・`active` | float 1.0 / 0.0 | 上の表と同じ |
| `/0/playState`・`loopEnabled` | float 1.0 / 0.0 | 上の表と同じ |
| `/{1-8}/colorR`・`colorG`・`colorB` | float 0.0〜1.0 | トラックの色。レイアウトの箱(box)の色になる。送り返す専用で、受け取らない。トラックがない位置には黒(0, 0, 0)を送る。背景と同じ黒なので、箱は見えなくなる |
